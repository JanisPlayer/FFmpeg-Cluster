# FFmpeg-Cluster
FFmpeg-Cluster is a distributed system designed for efficient video processing. It allows multiple clients to collaborate in encoding video segments concurrently, which are then combined into a single output file (or streamed via HLS). This project uses Flask-SocketIO for communication between the server and clients and FFmpeg for video processing.

## Usage:

### Requirements:
- [FFmpeg](https://github.com/btbn/ffmpeg-builds/releases)
- Python 3.10+
- Packages in [requirements.txt](requirements.txt) (`requests`, `Flask`, `Flask-SocketIO`, `python-socketio[client]`, `websocket-client`, `numpy`)

### Setup (Linux / Termux):
```bash
git clone https://github.com/JanisPlayer/FFmpeg-Cluster.git
cd FFmpeg-Cluster
chmod +x install.sh
./install.sh
source FFmpeg-Cluster-venv/bin/activate
```

### Setup (Windows PowerShell):
```powershell
git clone https://github.com/JanisPlayer/FFmpeg-Cluster.git
cd FFmpeg-Cluster
.\install.ps1
.\FFmpeg-Cluster-venv\Scripts\Activate.ps1
```

### Setup (Docker Compose):
```bash
docker compose up --build
```

### Starting the Server:
```bash
python3 server.py --required_clients 2 --file_name input.mp4 --ffmpeg_params "-c:v libsvtav1 -preset 6 -crf 30 -c:a aac -b:a 128k"
```

### Dynamic `segment_request` Examples:
- **Divide the video into 10-second base segments scaled by benchmark:**
```bash
python3 server.py --required_clients 2 --file_name input.mp4 --segment_request --segment_time 10 --ffmpeg_params "-c:v libsvtav1 -preset 6 -crf 30"
```

- **Minimal segment time of 10 seconds with benchmarking (weakest client as baseline):**
```bash
python3 server.py --required_clients 2 --file_name input.mp4 --segment_request --segment_time -10 --ffmpeg_params "-c:v libsvtav1 -preset 6 -crf 30"
```

- **10-second segments without benchmarking:**
```bash
python3 server.py --required_clients 2 --file_name input.mp4 --segment_request --segment_time 10 --benchmark_seconds 0 --ffmpeg_params "-c:v libsvtav1 -preset 6 -crf 30"
```

### Starting a Client:
```bash
python3 client.py --server_ip 192.168.0.86
```

With hardware encoder override and authentication key:
```bash
python3 client.py --server_ip 192.168.0.86 --key mysecret --ffmpeg_params_overwrite "-c:v h264_nvenc -preset p4 -cq 24"
```
